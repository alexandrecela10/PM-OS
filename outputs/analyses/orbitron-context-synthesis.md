# Orbitron Context Synthesis — for Asset Nova Case Study

Source: context-library/research/Orbitron/ (website captures, founder LinkedIn posts, NovaOS product screenshot). Analyzed 2026-08-26.

## 1. Asset Nova already exists on their roadmap

The website footer lists four products: **Nova OS · Flow NOVA · Comply NOVA · Asset NOVA**. Asset Nova is a named, planned product. The case study isn't inventing a product — it's proposing how to build one they've already committed to. Positioning must slot cleanly into this lineup.

## 2. NovaOS = composable agent studio (from the NovaStudio screenshot)

- Left panel: reusable agents — **FlowNova Agent, ComplyNova Agent, LeadNova Agent, Browser Agent, Doc Analyzer**
- Canvas: visual workflow builder (nodes like Demand Forecast → Stock Level → Inventory Check, trigger events)
- Right panel: integrations/blocks — Slack, Gmail, Webhook, Airtable, API, Condition, NovaOS AI Agent
- Bottom: run history with steps like **"Manager Review"** (human-in-the-loop is a first-class node) and **"ERP Sync"**

**Implication:** Asset Nova = a set of CPM-specific agents + workflow templates built in NovaStudio, composing FlowNova and ComplyNova agents as nodes. The prototype should visually echo this composability.

## 3. FlowNova capabilities we can reuse

Five modules: **Command Center** (control tower: monitoring, quantified recommendations, agentic execution) · **Integrated Business Planning** (forecasting, scenario modelling) · **Contracting & Procurement** (agentic sourcing, contract creation/negotiation, contract performance mgmt) · **Operations Optimisation** (scheduling, fuel, fleet) · **Logistics** (network, shipment, port optimisation).

Claimed metrics: 60–90% reduction in time-to-decision, 5–15% supply chain cost reduction, 10–15X ROI. **"Value and ROI guaranteed — commercial models structured around measurable outcomes."** → GTM should use outcome-based pricing.

## 4. ComplyNova capabilities we can reuse

Three modules: **Third Party Risk Management** (continuous vendor screening, risk scoring, onboarding with remediation tasks) · **Case Command Center** (agents open cases from signals, route to owners, evidence packs, approvals) · **Internal Audit Automation** (evidence collection mapped to controls, first-pass narratives, continuous readiness).

Configurable per tenant/geography. Evidence-first, defensible, approval workflows.

## 5. Founder philosophy (Ashu Gupta) — the hidden rubric

The case study will be judged against these beliefs:

1. **"How not to think SaaS while building AI products":** No static dashboards. (a) Verify the substrate — data stored, queryable, structured. (b) Write skills, not queries — versioned, owned, registered, reusable. (c) Render throwaway HTML dashboards on demand, no permanent surface. "Dashboards decay. Skills compound."
2. **Governance is the product:** 97% deployed agents, only 1/5 have governance. Three questions before deployment: Who owns the agent's decisions? What does it do outside its defined scope (escalation path)? How do we measure value created, not just activity? "Agentic AI is organizational redesign, not a technical rollout."
3. **Sovereign AI / "Weights, Not Wrappers":** For regulated industries, owning models/weights wins. Data residency matters (Aramco/KSA). Not a wrapper play.
4. **"Keep your alpha":** enterprises don't want to give away their edge to external AI vendors — value the customer's proprietary knowledge, keep it theirs.
5. Bio: Co-founder, ex-CTO Lean Technologies (MENA open finance, Forbes ME Fintech 50). Building "the Agentic OS for the Next Billion Workflows." Acquired Agnax 2025. MENA-first. Cares about: practical infrastructure not demos, MENA AI-native ecosystem, helping founders avoid mistakes.

## 7. What this means for the case study

1. **Position Asset Nova as the third NovaOS product**: CPM-specific agents (cost estimation, schedule risk, claims/contracts, O&M) composed with FlowNova (procurement, logistics, control tower) and ComplyNova (permits, HSE compliance, audit evidence) in NovaStudio.
2. **Demo style must be agent-native, not SaaS**: agents render views on demand, propose actions, humans approve at gates. Avoid presenting "a dashboard product."
3. **Bake governance in**: every agent in the demo has an owner, a defined scope, an escalation path, and a value metric. Answering Ashu's three questions unprompted = strong hire signal.
4. **GTM**: outcome-based commercial model (they already do "ROI guaranteed"), KSA-first (Aramco/NEOM-type giga-projects), sovereign/on-prem deployment option.
5. **Wow moment**: show the delay-cascade or compliance-gap scenario where Asset Nova orchestrates FlowNova + ComplyNova agents live — proving the platform compounding story, not a point solution.
